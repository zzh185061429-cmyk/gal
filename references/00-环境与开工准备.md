## 0.3 项目脚手架

双蓝本出身：租借男友 = vite + React 19 + Tailwind v4 自包含配置；幻璃镜 = StageDog `tavern_helper_template`（webpack 单文件内联）。**新项目直接用 SKILL.md §S0 的 StageDog 公共模板**（GitHub 公共模板，Use this template 建仓），下面是它的来路：

**`package.json` 核心依赖**：`react` `react-dom` `tailwindcss` `motion`（动画）`lucide-react`（图标）`typescript`。

**入口（酒馆 iframe 部署用幻璃镜式）**——等 jQuery ready 再挂载、`pagehide` 卸载：

```tsx
$(() => {
  const root = createRoot(document.getElementById('root')!);
  root.render(<App />);
  $(window).on('pagehide', () => root.unmount());
});
```

注意：酒馆助手注入的全局函数（`getChatMessages` 等）在 TS 里没有类型声明，项目里用 `declare` 或 `as any` 兜住即可，不影响运行。

## 0.4 本地调试闭环

1. `pnpm build` 后浏览器直接开产物（或 dev 服务器）裸跑前端——此时酒馆全局函数不存在，所有依赖点都必须走 `typeof === 'function'` 判空降级（SKILL.md §S4）。
2. 酒馆里开一条 **dev 界面正则**（默认 disabled，联调才开，字段逐解见 SKILL.md §S2）：

```json
{ "findRegex": ".*",
  "replaceString": "```\n<body>\n<script>\n$('body').load('http://localhost:5500/dist/<项目>/index.html')\n</script>\n</body>\n```",
  "placement": [1, 2], "markdownOnly": true, "disabled": true }
```

   地址端口与你的静态服务器一致即可。`$('body').load(URL)` 会把整页灌进该楼层 → 楼层变 iframe。
3. 真机全流程验收时再切换到 CDN 正式正则（SKILL.md §S2）。

## 0.5 构建与发布

两种做法（双蓝本各用一种）：

- **单文件内联（幻璃镜做法，推荐给 CDN 发布）**：webpack 把 JS/CSS 全部打进一个 `index.html`。CDN 只需 load 一个 html，**没有相对路径/子路径问题**。
- **目录发布（租借男友 dev 做法）**：vite 产出 `dist/`（html + assets），把整个 dist 目录随仓库发布；确保产物内资源引用是相对路径，否则在 jsDelivr 子路径下会 404——用单文件方案可绕开这一步。

**改版必 bump**：CDN 有缓存，发新版要换路径（坑 29）。发布三铁律见 SKILL.md §S6。
