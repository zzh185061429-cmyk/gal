# 排障决策树（按现象查）

> 用法：先找现象，按顺序排查，每步给出"在哪看、看到什么算异常"。**改一处验一处**，别一次改五个地方。
> 引用说明：「坑 N」= `pitfall-catalog.md` §13 同号条目；「§S2/S5/S6」= SKILL.md 施工阶段；`00` = 本目录 `00-环境与开工准备.md`。

## 现象 1：楼层显示原始文本/代码块，没变成 gal 画面

1. 酒馆正则面板：界面正则是否 enabled？（dev 正则默认 disabled，联调才开）
2. `placement` 是否含 `2`（AI 楼显示）；`markdownOnly` 是否为 `true`（→ SKILL.md §S2）
3. `findRegex` 是否被另一条正则抢先消费（多条正则有顺序，前一条替换后后一条匹配不到）
4. DevTools 查该楼 DOM：有没有生成 `<iframe>`？有 iframe 但白屏 → 现象 2
参见：坑 29、00 §0.4。

## 现象 2：iframe 白屏 / 黑屏

1. 右键该楼 → 检查 → console 报错第一行
2. Network 里 index.html 请求是否 404 → CDN 路径拼写、仓库分支名、@master 是否推上去了
3. 用的目录发布？→ assets 是否 404（相对路径问题）→ 换单文件内联构建（00 §0.5）
4. console 有 JS 异常 → 通常是酒馆全局函数未判空（坑 18），或某模块在渲染期直接调 `getChatMessages`
参见：坑 18/29。

## 现象 3：文字在但样式全丢

1. tailwind v4 入口是否 `@import "tailwindcss";`（index.css 第一行）
2. 构建产物里 CSS 是否被打进去（单文件构建看 `<style>`，目录发布看 assets/*.css）
3. 类名是自定义 CSS（如里程碑代码）还是 tailwind 原子类——混用时要保证两套都在

## 现象 4：点屏幕没反应

1. 本地浏览器裸跑？→ `triggerSlash` 不存在是**正常**，发送相关功能本来就不该有反应（坑 18）
2. console 有没有报错；`isTyping` 是否永远 true（打字机回调没接好，点击全被"跳过打字"吞掉）
3. 点击目标是不是被全屏遮罩/弹窗挡住（DevTools 元素选择器点一下看命中谁）
4. 事件冒泡：交互元素内部点击要 `e.stopPropagation()`（参照 `GameScreen.tsx:997-1001`）

## 现象 5：一打字就卡，立绘 CG 跟着一顿一顿

→ 打字机状态写进主组件了。对照里程碑 `09-里程碑代码-阶段一.md` 的 `TypingText.tsx`：内部 useState + `React.memo` 比较器 + rAF（坑 1）。判据：React DevTools 高亮更新，打字时如果整个 App 在闪，就是它。

## 现象 6：对话没被识别，全变旁白

1. 全角标点：`：` `“”`（坑 3）——把可疑行贴进正则调试器跑 `^(.+?)\[(.+?)\]:"(.+)"$`
2. 行内混了动作/前后缀（坑 2）——全行锚定就是这么设计的，改 AI 输出不是改正则
3. AI 用了玩家名当说话人且被 `isUser` 吞成立绘缺席（坑 6）——这是特性不是 bug
4. 做了全角容错层还识别不出 → 检查容错替换是否在 stripThinking **之前**执行（容错层规范见 `12-自定协议与题材适配.md` §2.6）

## 现象 7：思维链出现在正文里

1. 提取顺序：必须先 `stripThinking` 再 `/<content>/`（坑 4）
2. 该思维标签不在剥离清单（`<reasoning>` 之类变体）→ 加进 `THINKING_PAIRS`（坑 5）
3. 未闭合标签（只有 `<think>` 没有 `</think>`）→ 成对正则天然不匹配，考虑加"无闭合则切到正文标签前"的兜底

## 现象 8：立绘不显示 / 差分切换不动

1. Network 看图片 URL 是否 404（postimages 直链复制全没）
2. `EMOTION_MAP` 里有没有这个中文情绪；`spriteOf` 回退链是否生效（坑 7/8）
3. 该说话人被 `isUser` 判成玩家（坑 6）
4. 立绘层 z-index 被背景盖住（里程碑 CSS：stage z-5 > bg z-0，textbox z-10）

## 现象 9：同屏立绘超了 / `<user>` 占了台

1. 装配机是否照抄 `slice(-3)` 三槽位（坑 10）
2. 解析层 `<user>` 行 `sprite` 是否置空（坑 9）
对照：`10-里程碑代码-阶段二.md` 的 useEffect 装配块。

## 现象 10：生成期间画面跳走 / 生成完不自动跳新楼

1. `/trigger` 是否带 `await=true`（坑 14）
2. `startGenerating`/`finishGenerating` 是否在 try/finally 里成对出现（坑 15）
3. `finishGenerating` 里是否有 `setViewingFloorId(null)`（解锁=归位）

## 现象 11：回看历史楼再回来，阅读进度丢了

→ 按"上次解析 key"比对了吗：只有本楼内容真变才清零（坑 17）。事件抖动（MESSAGE_UPDATED/CHAT_CHANGED）触发的重解析不得重置。

## 现象 12：删楼后出现空 iframe 壳

→ 用的是 `deleteChatMessages`（只清空内容）→ 换 `/cut`（坑 19）；删完发刷新事件了吗（坑 24）。

## 现象 13：重roll 后正文换了但变量没变

1. console 找 `[regen] 变量解析失败` → MVU 没装/没就绪（坑 22），装框架脚本或接受降级
2. `Mvu.parseMessage` 传的是剥链**全文**还是只有正文？变量块在 `<content>` 外（SKILL.md §S5 步骤⑤）
3. 仍不动 → 框架落盘语义问题，补 `Mvu.replaceMvuData` 显式写回（原教程标注的未验证点，以真机实测为准）

## 现象 14：全屏被父页顶掉 / 退出后高度错乱

1. 伪全屏样式注入了吗：父页 head 有没有 `*-fs-hide` 的 `<style>`（SKILL.md §S6）
2. `parent$` 拿不到（跨域/时序）→ 前提是同源 iframe，检查加载方式
3. 退出后 burst 挂了吗：`fullscreenchange` → `guard.burst()`（SKILL.md §S6、坑 26）

## 现象 15：锁定期间新楼层冒出来

1. 锁定前端脚本启用了吗（酒馆助手脚本面板）
2. MutationObserver 挂在 `#chat` 还是 body（后者也行但更吵）；`childList: true, subtree: true`（坑 27）
3. 新楼 `.mes` 的 mesid 选择器匹配式是否和当前锁定的楼号拼对

## 现象 16：从酒馆删锁定楼，iframe 还是没了

1. 父页 head 有没有 `<script id="…-lock-protect-script">`（没注入成功 → 看 SKILL.md §S6 锁定前端脚本的注入逻辑）
2. console 有没有 `拦截 remove()` 警告——没有=拦截器没生效；有但还删了=走了第四条路径（如 innerHTML 重写），把该路径补进拦截
3. 别忘了 jQuery 版本差异：`$.fn.remove` 必须在 jQuery 加载后 patch

## 现象 17：天气乱跳 / 被台词改了

→ 坑 31（回写只扫旁白行）+ 坑 32（季节表+持续性+相似组+种子）。

## 现象 18：NPC 二次出场立绘消失

→ AI 本楼没打标 + 没从登记表恢复（坑 35）。解析前把 `evilRegistry/normalRegistry` 合进 `dynamicSprites`。

## 现象 19：改了代码，酒馆里还是旧的

1. 构建了吗、dist 推了吗
2. CDN 缓存：换路径（bump 仓库/分支/tag）而不是等缓存过期（坑 29）
3. 正式正则里的地址更新了吗

## 通用第一招

任何诡异现象，先做三件事：① console 报错读第一行；② Network 看红请求；③ 把现象缩小到"解析错了 / 状态错了 / 渲染错了"三段之一（贴夹具进 `parseScriptContent` 单测 = 验解析；console 打 `viewingFloorId/targetFloorId` = 验状态；React DevTools = 验渲染）。
