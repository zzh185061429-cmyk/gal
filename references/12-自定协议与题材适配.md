# 自定协议与题材适配（去参照项目化）

> SKILL.md 施工路径与里程碑代码教的是"双蓝本怎么定协议"。本章教"**你怎么定自己的协议**"：哪些规矩动不得，哪些全是你的自由，以及换题材时要动哪些点。（「坑 N」= `pitfall-catalog.md` §13 同号条目。）

## 1. 四条动不得的（改了就塌）

1. **全行锚定 + AI 侧同步自检**：解析正则锚整行，AI 输出纪律（半角、不混写）写进 COT。这两半必须同一条心——改正则不改 COT，或反之，都会把识别率打穿（坑 2/3）。
2. **先剥思维链，再提取正文**：顺序反了思维链里的正文标签就污染结构（坑 4/5）。
3. **旁白兜底**：任何不认识的行都落旁白。新行类型只能"加在兜底之前"，永远不要让兜底消失。
4. **`<user>` 不占立绘位**：玩家行的 sprite 恒空（坑 9）。

## 2. 自由度清单（每一项都可以改成你的）

### 2.1 正文标签名

`<content>` 只是名字。改法：提取正则一处 + 重roll 提取处一处（SKILL.md §S5）。建议把标签名收成**单一常量**，两处引用同一来源，别散落魔法字符串。

### 2.2 情绪标签的位置

| 方案 | 写法 | 权衡 |
|---|---|---|
| 行内（参照项目） | `名[情绪]:"…"` | 省行数；差分与台词天然绑定；解析稍复杂 |
| 独立行 | `[情绪:角色名:生气]` | 正则最简、可挂整段；每换一次情绪多一行，AI 易忘 |

教学默认行内。想换独立行：`SCENE_RE` 同款思路加一条 `^\[情绪:(.+?):(.+?)\]$`，把游标从 `currentLocation` 换成 `currentEmotion`。

### 2.3 玩家记号

`<user>` / `我` / 玩家名 三重兼容已在 `isUser`。你还可以加别名表（见 2.7）。

### 2.4 scene 层级深度

```ts
// 任意层级（幻璃镜，推荐）——正则最短
const SCENE_RE = /^\[scene:([^\]]+?)\]$/;
// 固定两级（租借男友）
const SCENE_RE = /^\[scene:([^/\]]+)(?:\/([^\]]+))?\]$/;
// 单级扁平（校园/室内剧够用）
const SCENE_RE = /^\[scene:([^\]]+?)\]$/ + 场景表只收单段 key
```

层级越深，图要得越多——**图预算先于层级**：没那么多图就别设计四级地点。

### 2.5 新行类型（例：低语）

想加 `名((低语)):"…"` 之类，三步：
1. 在兜底**之前**插一条分支（顺序：具体 → 宽泛，`DIALOG_RE` 必须在最后一批）；
2. `ScriptLine` 加字段或复用 emotion；
3. COT 加一条对应格式自检。
模板照抄 `parser.ts` 里 dialog 分支的形状即可。

### 2.6 全角/变体容错层（可选，有代价）

个人自用想容忍 AI 手滑：把字符类放宽 `[:：]`、`["“”]`。**代价**：AI 纪律从此靠容错养懒，分发给别人的卡建议收紧回去。若加，放在 `stripThinking` 之后、行匹配之前做一次整行归一化，并保留原始行以便调试。

### 2.7 群像与别名

角色多个称呼（"晋王""皇上"指同一人）：给角色定义加 `alias` 数组，查找时 `name === x || alias.includes(x)`——幻璃镜解析器原生支持（`scriptParser.ts:105-111`）。舞台装配按"主名"聚合，别让同一人占两个槽。

### 2.8 COT 条目重写模板

把 SKILL.md §S1 的五条格式自检换成你的协议，逐条对应：

```
- 对话必须是 `名[情绪]:"台词"`！（← 你的行格式）
- 引号冒号半角！动作描写不混进对话行！（← 全行锚定）
- <你的正文标签> 第一行是 [scene:…]！（← 你的场景规则）
- 地点变一次插一个新 [scene:..]！（← 换景规则）
- 玩家一律写 <user>，不写玩家名！（← 你的玩家记号）
```

## 3. 题材适配表（换皮要动哪些点）

| 要素 | 古风探案（幻璃镜） | 现代都市（租借男友） | 校园/职场（建议） | 纯文字模式 |
|---|---|---|---|---|
| 地点层级 | 3~4 级（皇城/衙署/钦天监/漏刻房） | 两级（别墅/客厅） | 单级（教室、天台） | 可保留但只做文字横幅 |
| 场景表规模 | 大（含天气/昼夜变体） | 中 | 小 | 零 |
| 差分/角色 | 5~10 差分/核心角色 | 3~6 | 3~5 | 零（名牌+头像即可） |
| 池子（扩展篇） | 路人/邪异/宅邸 | 路人可选 | 同学/老师池 | 不需要 |
| 天气昼夜 | 全套 | 简化 | 可选 | 不需要 |
| 需要动的文件 | — | 场景表+差分表+EMOTION_MAP | SCENE_RE 单级+扁平 SCENES | 里程碑代码删 Stage/背景层，保留名牌+分页 |

**通用替换流程**（30 分钟级）：
1. 改 `assets.ts`：CHARACTERS/SCENES 换成你的图与名字；
2. 改 `EMOTION_MAP`：情绪词与你的差分对齐（AI 常用什么词就映射什么词）；
3. 改 COT 五条（§2.8 模板）；
4. 首楼夹具按你的题材重写一份（结构照抄蓝本样本：`[scene:]` 开头、旁白成段、对话干净）；
5. 跑 `09/10-里程碑代码` 的自测清单回归。

## 4. 什么值得抄、什么不值得抄

- **值得抄**：全程红线、先剥后提、旁白兜底、三槽位装配、生成锁成对调用、幂等世界书写入、洗牌袋池子。
- **不必照抄**：幻璃镜的双端布局/节气黄历/案件系统（题材绑定）、租借男友的物理跳楼 floorNav（第一代，被虚拟导航取代）、四大池子全套（你的题材未必需要邪异池——池子按需各拆各装）。
